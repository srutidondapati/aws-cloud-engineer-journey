| Service | Type | Use this when... |
|---|---|---|
| **S3** | Object storage | You need to store data backups,images, documents that are accessed by a unique key or URL. |
| **EBS** | Block storage | You need to work on a single EC2 instance for MySQL databases. |
| **EFS** | Shared File System | Multiple EC2 instances working on shared content or collaborative files. |
| **RDS** | Database Service | Organizes data into tables, useful for structured systems and complex queries. |
| **DynamoDB** | NoSQL Key-Value | Flexible items in comparison to RDS, looking items up using key |
